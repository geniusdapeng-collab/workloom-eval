# 功能与验证矩阵

秀吉系统 把用户的岗位需求转为员工初版，装配知识、工具、技能和真实模型，在业务仿真中评测，再生成候选版本、比较报告和使用建议。P0、P1、P2 表示产品需求层次；本表描述当前源码已经提供的入口、执行行为及其验证边界。

## 如何阅读证据

实现依据和执行证明分别记录：**A** 表示完整阅读实现所得；**B** 表示运行记录、自动化断言或元数据；**D** 表示尚未执行的环境条件或使用假设。没有用源码存在代替真实外部执行证明。

| 执行层次     | 含义                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------- |
| 逻辑回归     | 真实服务代码配明确的模型 stub 或内存 fixture，验证控制流、权限和失败行为；不能证明真实模型质量  |
| 本地集成     | 实际 SQLite、HTTP 监听器、受限子进程或浏览器执行；外部接口由本地 fixture 提供，不是客户生产系统 |
| 真实模型     | 正式 API 发出模型请求，有实际模型标识、用量及任务结果；工具仍可为仿真                           |
| 外部环境验收 | 指定客户系统、远端训练提供方或生产部署目标上的实际结果；需要相应回执，不能从本地测试外推        |

文档所引测试是对应行为的可运行验证入口。全套测试数量、CI 状态、Git 提交和界面截图以本次发布的验收记录为准，不在此固化一个会随源码增长失效的总数。

## 使用前需要明确的条件

- 模型密钥从环境或专用接口进入进程内存，不写入资源记录、能力包和报告。通过界面配置的会话密钥在重启后需重新配置。
- 导入知识默认草案、`allowedModelEgress=false`。管理员或资产责任人应先按实际数据授权调整，禁止为了通过测试而默认扩大资料出域范围。
- 公开搜索使用单独工具接口；客户端身份、订单标识、联系方式、凭据和未授权知识原文在发送前检查。规则检查不能被宣传为完整的语义数据防泄漏认证。
- 任意外部服务的功能、权限、数据条款与运行配额，都需要在实际接入环境验证。源码和本地接口测试不构成云部署、外部训练或客户生产执行回执。
