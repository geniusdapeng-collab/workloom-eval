## 当前环境边界

1. 服务实际运行在本机回环地址；没有目标公网域名或云服务器部署回执。
2. DeepSeek默认推理、Search和Fetch已有各自真实调用记录；当前没有已核实的DeepSeek公共托管微调端点，不能声称完成其权重微调。
3. 微调任务和结果模型适配、真实外部部署适配均有可执行代码及本地真实HTTP契约测试；接入具体第三方生产目标仍需对应权限与回执。
4. 浏览器/脚本只运行已注册任务；当前脚本为声明式数据处理。扫描PDF与任意宿主代码执行不属于已声明支持格式。
5. Dockerfile提供部署路径；若本机没有Docker引擎，不能声称本机容器镜像构建已经通过。
