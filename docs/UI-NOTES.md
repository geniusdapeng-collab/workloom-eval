# 秀吉系统 用户界面

前端以员工版本为工作上下文，采用附件参考的深蓝工作台、紫色主操作、青色执行状态。所有数量、分数、运行状态和报告均来自 API，未评测的参考资产不展示模拟成绩。

## 工作路径

1. 总览描述岗位需求，或使用售后、分析、内容岗位例句生成输入。
2. 创建向导选择真实模型和可使用的知识、工具、技能，可在初版生成后自动试岗。
3. 任务中心显示排队、运行、用量、失败和实际结果，结果可直达员工、运行与候选版本。
4. 员工详情绑定能力、冻结新版本、启动试岗和自动迭代。
5. 仿真测试集编辑初始业务状态、故障注入、输入、预期和断言，明确用途隔离。
6. 运行详情采用场景、执行过程、验收三栏，显示调用回执、结果状态、断言、用量和复核入口。
7. 自动迭代保留基线、候选、最佳版本和停止原因；版本比较展示配置和已有评测条件。
8. 报告支持 Markdown、JSON、HTML 导出；版本支持能力包导出。
9. 班组创建通过成员、版本和职责表单配置，岗位记忆有作用域、来源和失效时间。
10. 影子、部署、回退、技能修复、微调任务与训练数据导出分别提供 API 表单。
11. 私有节点登记展示一次性令牌，显示心跳和能力；浏览器评测提交受控节点。
12. 经验库保留来源与核验；版本组合查询质量、时延、成本的非支配候选。
13. 设置中配置模型与进程内密钥、真实连通测试，以及只增审计事件。

## 状态与交互

API 失败显示具体错误；写表单校验必填、JSON、URL和数值范围，提交中禁用重复操作。删除使用明确确认。只读角色禁用写入口。模态框支持 Escape、焦点保持、Tab 焦点约束和关闭后恢复。密钥字段不回显。评测、评分和任务取消保留实际状态。

1440/1280 桌面布局与 390 移动布局共用组件；移动端导航折叠、证据三栏纵向展开、宽表格限于独立滚动容器，避免页面横向溢出。

## 异常核对与断点继续

- 设置页只给管理员展示未决供应商请求；核对表单记录管理员提供的供应商依据。已完成请求要求实际响应 ID 和完整用量，未核对前不重发相同请求。
- 等待核对的真实部署提供“核对远端状态”，该动作只读取状态，不再次提交部署或回退。
- 评测任务详情列出持久化完成场景；中断、失败或取消的仿真任务可继续未完成场景，服务端再次核验冻结条件、原预算和未决请求。盲测断点只展示摘要。
- 测试集用途创建后固定，用例不能改所属测试集。封存场景详情不提供编辑入口。

## 文件

- src/App.jsx：应用壳、会话、状态刷新与业务动作。
- src/pages/：按业务拆分的页面、向导和三栏证据详情。
- src/view-utils.js：页面搜索与显示辅助。
- src/components.jsx：可访问性表单、模态框、表格与状态组件。
- src/forms.js：业务字段和任务参数。
- src/api.js：请求、错误、导出和显示格式。
- src/styles.css：视觉系统和响应式布局。
- src/main.jsx、index.html、vite.config.mjs：启动与构建。
